# BroadcastLoom

BroadcastLoom is a cloud-based, real-time media processing engine with auto-scaling capabilities, delivering high-performance streaming services.

With BroadcastLoom, you get a lightweight tool that stays out of your way.

**What you get**

- BroadcastLoom is a cloud-based, real-time
- media processing engine with auto-scaling
- capabilities, delivering high-performance streaming services

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/BroadcastLoom.git`
2. `cd BroadcastLoom`
3. Install in editable mode: `pip install -e .`

## Configuration

BroadcastLoom is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
